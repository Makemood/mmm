# Высокое напряжение

Фанатская мини-игра по мотивам фильма **«Адреналин 2»** (*Crank: High Voltage*). Это не официальный продукт: в проекте нет кадров, музыки и моделей из фильма. Есть только идея.

У героя украли сердце и поставили искусственное. Его надо постоянно подпитывать электричеством. Заряд падает каждую секунду. **Ноль — смерть.**

Ты бегаешь по ночному городу, стреляешь из электропушки, заряжаешься у синих щитков и подбираешь жёлтые батареи с бандитов. На полном заряде бежишь быстрее. На низком темнеет экран и слышно, как садится сердце (звук можно добавить самому, см. ниже).

Игра уже рассчитана на несколько игроков: у каждого своё сердце. Общий город, общие щитки, общие бандиты. Друг друга тоже можно подстрелить — за чужую смерть дают заряд.

## Что будет, когда всё собрано правильно

После кнопки **Play**:

- ночь, фиолетовый туман, неоновые окна и вывески;
- площадь с розовым сердцем и надписью «ВЫСОКОЕ НАПРЯЖЕНИЕ»;
- слева сверху полоска **«ЗАРЯД СЕРДЦА»**;
- в руках пушка **«Вольтган»**;
- синие столбы света — электрощитки;
- по улицам ходят бандиты.

В режиме редактирования (до Play) города нет. Его строит скрипт в момент запуска. Пустая база на старте — это нормально.

## Что нужно

Уже установленный **Roblox Studio**. Аккаунт Roblox. Больше ничего обязательного нет.

Дальше два пути. Выбери один.

- **Способ А** — Rojo. Удобно, если правишь код в Cursor или VS Code и хочешь, чтобы Studio подхватывала файлы сама.
- **Способ Б** — руками. Ничего дополнительно ставить не нужно: создаёшь скрипты в Explorer и вставляешь код. Для первого раза так даже понятнее.

Оба способа дают одну и ту же игру.

## Способ А. Rojo

Rojo — мостик между папкой с файлами и Studio. Файл `default.project.json` в корне говорит ему, какой файл в какой сервис положить.

### 1. Поставь программу Rojo 7

Официальная инструкция (там кнопки под Windows, macOS и Linux):

https://rojo.space/docs/v7/getting-started/installation/

Самый прямой путь, если инструкция кажется длинной:

1. Открой https://github.com/rojo-rbx/rojo/releases
2. Скачай архив под свою систему (для Windows это файл вроде `rojo-...-windows-x86_64.zip`).
3. Распакуй. Внутри будет программа `rojo` (на Windows — `rojo.exe`).
4. Открой терминал **в папке этого проекта** (там, где лежит `default.project.json`).
5. Проверь, что программа находится. Если она не прописана в PATH, указывай путь к файлу, например:
   - Windows: `C:\путь\к\rojo.exe --version`
   - macOS / Linux: `./rojo --version` из папки, куда ты её положил

Должна напечататься версия 7.x. Версия 6 не подойдёт: у неё другой формат проекта.

### 2. Поставь плагин Rojo в Studio

На той же странице релизов есть файл **`Rojo.rbxm`** (плагин).

1. Скачай `Rojo.rbxm`.
2. Открой Roblox Studio.
3. Перетащи файл `Rojo.rbxm` в окно Studio. Studio спросит, установить ли плагин. Соглашайся.

Плагин также ставят командой `rojo plugin install`, если программа Rojo уже работает. Появится вкладка или кнопка **Rojo** в меню Plugins.

### 3. Подключи проект

1. В терминале, в папке проекта, запусти:

   ```bash
   rojo serve
   ```

   Если команда `rojo` не находится, вызывай программу по полному пути, как в шаге 1. Окно терминала не закрывай: пока оно работает, Studio может читать файлы.

2. В Studio создай новое место: **File → New**. Подойдёт шаблон Baseplate.
3. Открой плагин Rojo и нажми **Connect**. Адрес по умолчанию `localhost:34872`. Его трогать не нужно, если `rojo serve` не написал другой порт.
4. В Explorer появятся скрипты: `Config`, `GameServer` и остальные из таблицы ниже.

### 4. Сохрани и запусти

**File → Save** (или Ctrl+S / Cmd+S). Потом **Play** (треугольник сверху или клавиша F5).

### Собрать файл места без кнопки Connect

Если хочешь один файл, который открывается двойным щелчком:

```bash
rojo build -o Adrenalin.rbxlx
```

Дальше в Studio: **File → Open** и выбери `Adrenalin.rbxlx`.

Файл `.rbxlx` в git не нужен, он в `.gitignore`. Его можно собирать заново когда угодно.

## Способ Б. Вставить скрипты руками

Rojo для этого способа не нужен.

### Подготовь Studio

1. **File → New → Baseplate**.
2. Включи два окна: вкладка **View → Explorer** и **View → Output**.  
   Explorer — дерево игры. Output — чёрное окно, куда игра пишет сообщения и красные ошибки. Без Output ты не увидишь, если что-то названо не так.
3. Сохрани место: **File → Save**, Ctrl+S.

### Как вообще создать скрипт

Повтори это для **каждой** строки таблицы:

1. В Explorer найди родителя (например `ServerScriptService`). Он уже есть в пустом месте, создавать сервисы не нужно.
2. Правый клик по родителю → **Insert Object**.
3. Выбери тип **точно** как в таблице: `Script`, `LocalScript` или `ModuleScript`. Это разные вещи:
   - **Script** — работает на сервере, запускается сам.
   - **LocalScript** — работает на твоём компьютере (мышь, экран).
   - **ModuleScript** — сам не запускается. Его подключают другие скрипты через `require`. В конце такого файла есть `return`.
4. Имя по умолчанию будет `Script` / `LocalScript` / `ModuleScript`. Переименуй (двойной щелчок по имени или F2) **точно** как в колонке «Имя». Русские буквы в имени пушки не нужны: имя скрипта пиши латиницей, как в таблице.
5. Двойной щелчок по скрипту откроет редактор. Там уже есть короткая заготовка (`print("Hello world!")` или `return {}`).
6. Выдели всё (Ctrl+A), удали, вставь **весь** файл из колонки «Файл». Не выкидывай верхние комментарии и последнюю строку `return`, если она есть.
7. Закрой вкладку скрипта. Studio сама держит изменения, но место всё равно сохрани (Ctrl+S).

Сначала создай все девять объектов, и только потом жми Play.

### Таблица: какой файл куда

| Файл в папке проекта | Имя в Explorer | Тип | Куда вставить |
| --- | --- | --- | --- |
| `src/ReplicatedStorage/Config.lua` | `Config` | **ModuleScript** | `ReplicatedStorage` |
| `src/ServerScriptService/GameServer.server.lua` | `GameServer` | **Script** | `ServerScriptService` |
| `src/ServerScriptService/MapBuilder.lua` | `MapBuilder` | **ModuleScript** | `ServerScriptService` |
| `src/ServerScriptService/ChargeService.lua` | `ChargeService` | **ModuleScript** | `ServerScriptService` |
| `src/ServerScriptService/WeaponService.lua` | `WeaponService` | **ModuleScript** | `ServerScriptService` |
| `src/ServerScriptService/EnemyService.lua` | `EnemyService` | **ModuleScript** | `ServerScriptService` |
| `src/StarterPlayer/StarterPlayerScripts/WeaponClient.client.lua` | `WeaponClient` | **LocalScript** | `StarterPlayer` → `StarterPlayerScripts` |
| `src/StarterPlayer/StarterCharacterScripts/ChargeEffects.client.lua` | `ChargeEffects` | **LocalScript** | `StarterPlayer` → `StarterCharacterScripts` |
| `src/StarterGui/ChargeHUD.client.lua` | `ChargeHUD` | **LocalScript** | `StarterGui` |

`StarterPlayerScripts` и `StarterCharacterScripts` уже лежат внутри `StarterPlayer`. Их не надо создавать заново.

Суффиксы `.server.lua` и `.client.lua` существуют только на диске, чтобы Rojo понял тип. В Explorer их **нет**. Файл `GameServer.server.lua` становится скриптом с именем `GameServer`.

После вставки дерево должно выглядеть так:

```
ReplicatedStorage
  Config                 ModuleScript
ServerScriptService
  GameServer             Script
  MapBuilder             ModuleScript
  ChargeService          ModuleScript
  WeaponService          ModuleScript
  EnemyService           ModuleScript
StarterPlayer
  StarterPlayerScripts
    WeaponClient         LocalScript
  StarterCharacterScripts
    ChargeEffects        LocalScript
StarterGui
  ChargeHUD              LocalScript
```

### Чего не надо создавать руками

Эти вещи появляются сами, когда игра запускается. Если сделать их заранее и ещё раз из скрипта, будут дубли.

| Что появится само | Где | Зачем |
| --- | --- | --- |
| Папка `Remotes` и событие `FireWeapon` | `ReplicatedStorage` | Клиент сообщает серверу, куда ты выстрелил |
| Папка `Map` | `Workspace` | Весь город |
| Папка `Enemies` | `Workspace` | Бандиты |
| Папка `Pickups` | `Workspace` | Жёлтые батареи |
| Папка `Effects` | `Workspace` | Следы выстрелов |
| Инструмент `Вольтган` | `StarterPack` | Пушка, которую выдают при появлении |

Город, щитки и бандиты тоже создаёт `MapBuilder`. В редакторе их нет — они есть только во время Play. Когда нажимаешь Stop, всё, что скрипт создал в Play, пропадает. Это нормально. Чтобы сохранить **свои** модели из Toolbox, ставь их до Play и сохраняй место. Не копируй детали из режима Play: Studio их не сохранит.

## Как проверить

1. Нажми **Play** (F5).
2. Открой **Output**. Должны быть строки (числа могут чуть отличаться):

   ```
   [Адреналин] Сервер запускается...
   [Адреналин] Город собран: зданий 10, щитков 8, точек бандитов 6.
   [Адреналин] Бандиты вышли на улицы: 6
   [Адреналин] Готово. Сердце тикает — не стой на месте.
   [Адреналин] Интерфейс заряда готов
   [Адреналин] Прицел готов. ЛКМ — стрелять.
   ```

   Если первой строки нет — `GameServer` не Script, выключен (галочка Disabled) или его нет в `ServerScriptService`.

3. Осмотрись. Ты стоишь на площади лицом к сердцу. Справа впереди синий щиток.
4. Следи за полоской. Если стоять, она падает примерно на 2% в секунду.
5. Подойди к синему столбу. Появится подсказка **«Зарядить сердце»**. Удерживай **E**, пока заряд не пойдёт вверх. После этого щиток на 12 секунд остывает (становится оранжевым), а бандиты слышат шум и могут прибежать.
6. **ЛКМ** — очередь из пушки. Попадание рисует вспышку и голубой след. Попадание в голову бьёт сильнее.
7. Найди бандита (красная надпись «БАНДИТ»). Убей его. С него падает жёлтая батарея: подойди или нажми подсказку «Подобрать».
8. Залезь на крышу. Рядом со спавном есть обычные ступеньки с табличкой «НА КРЫШУ». У домов ещё есть решётчатые лестницы `TrussPart`: встань на решётку и держи пробел или иди вперёд. На крыше бандит достаёт хуже, но сердце всё равно садится.
9. Дождись нуля специально один раз. Персонаж умирает, через несколько секунд появляется снова. Заряд после смерти не становится полным, но и не остаётся нулём — иначе ты умер бы сразу ещё раз. Число лежит в `Config.Charge.RespawnFloor`.

Остановить тест: кнопка **Stop** (квадрат) или Shift+F5.

### Два игрока на одном компьютере

1. Вкладка **Test** (в новых версиях Studio она может называться так же в меню тестирования).
2. Режим **Server & Clients** / **Start Server and Players**, игроков поставь **2**.
3. Start.

Откроются два окна. У обоих своя полоска. Можно стрелять друг в друга: убийство тоже даёт заряд. Щитки и бандиты общие. Это уже заготовка режима «все отравлены» — не хватает только экрана победы, когда остался один живой.

В списке игроков сверху есть колонка **«Заряд»**. Это серверная цифра, её удобно сверять с полоской.

### Управление

| Действие | Клавиша |
| --- | --- |
| Идти | WASD или стрелки |
| Прыжок | Пробел |
| Стрелять | Левая кнопка мыши, можно удерживать |
| Зарядиться / подобрать | Удерживать E у щитка, нажать E у батареи |
| Рюкзак, если пушка пропала из рук | Клавиша `` ` `` (тильда, слева от 1) или цифра 1 |

На телефоне Roblox сам показывает кнопку прыжка и кнопку действия у щитка. Выстрел — касание экрана.

## Как устроена игра

Сервер решает всё, от чего зависит честность: заряд, урон, смерть, подбор батареи. Твой компьютер только рисует экран и отправляет направление выстрела. Если кто-то подменит полоску у себя, сервер этого не спросит.

```
Игрок нажимает ЛКМ
    → WeaponClient шлёт направление в RemoteEvent FireWeapon
    → WeaponService на сервере пускает луч от головы
    → если луч попал в человека или бандита, сервер снимает здоровье
    → за убийство ChargeService прибавляет заряд

Каждые 0.25 с ChargeService уменьшает заряд.
Ноль → здоровье персонажа становится 0.
```

Щиток и батарея вообще без RemoteEvent: кнопка `ProximityPrompt` срабатывает на сервере, и сервер сам прибавляет заряд.

### Что делает каждый скрипт

| Скрипт | Роль |
| --- | --- |
| `Config` | Все числа: урон, скорость расхода, цвета, сид карты. Меняй баланс здесь. |
| `GameServer` | Единственный серверный скрипт, который запускается сам. По очереди включает остальные модули. |
| `MapBuilder` | В начале игры удаляет стандартную пластину, ставит ночь и собирает город из деталей. |
| `ChargeService` | Хранит заряд, тратит его, ускоряет на высоком заряде, обслуживает щитки. |
| `WeaponService` | Создаёт пушку и считает попадания лучом. |
| `EnemyService` | Собирает бандитов из деталей, ведёт их по улицам, роняет батареи. |
| `ChargeHUD` | Полоска, предупреждение, подсказка. Сам заряд не меняет. |
| `ChargeEffects` | Темнота, размытие и красные края экрана, когда заряда мало. Скорость бега не трогает. |
| `WeaponClient` | Читает мышь и рисует прицел. |

Почему скрипты лежат в разных местах:

- `ChargeHUD` в `StarterGui`, потому что это интерфейс.
- `ChargeEffects` в `StarterCharacterScripts`, потому что эффект привязан к жизни персонажа: умер — скрипт исчез вместе с персонажем и убрал размытие.
- `WeaponClient` в `StarterPlayerScripts`, потому что пушка выдаётся заново после каждой смерти, а скрипт мыши должен жить между смертями.

### Заряд

| Откуда | Что происходит |
| --- | --- |
| Старт | 70 |
| Каждую секунду стоя | −2 |
| Каждую секунду в движении | −1.5 (трата минус маленькая прибавка за бег) |
| Прыжок | +0.25, не чаще чем раз в треть секунды |
| Полная зарядка у щитка | +38 за 3 секунды удержания |
| Убийство | +16 |
| Батарея | +20 |
| Выстрел | −0.35, ниже 1% пушка молчит |
| 75 и выше | бег быстрее |
| 35 и ниже | экран темнеет, бег чуть медленнее |
| 0 | смерть |
| После смерти, если было меньше 50 | поднимают до 50 |

Точные числа — в `Config`. Подписи на экране на русском.

Щиток после использования остывает 12 секунд и на это время зовёт бандитов в радиусе 140 студов. Стоять на одном щитке можно, но это шумно.

Обычная полоска здоровья (тонкая, под зарядом) — это не сердце. Её снимают пули и удары. Сердце живёт отдельно и убивает только на нуле. Короткий щит в первые секунды после появления закрывает от бандитов, но не от остановившегося сердца.

## Где крутить баланс

Открой `Config` (файл `src/ReplicatedStorage/Config.lua`).

| Хочешь | Поле |
| --- | --- |
| Дольше жить стоя | уменьши `Charge.DrainPerSecond` |
| Щиток жирнее | `ElectricBox.ChargeAmount` |
| Бандиты злее | `Enemy.AttackDamage`, `Enemy.AggroRange` |
| Пушка слабее | `Weapon.Damage` |
| Другой район | `Map.Seed` — любое целое число, город пересобирается |
| Свой звук | `Sounds.Shot`, `Sounds.Recharge`, `Sounds.Heartbeat`, `Sounds.Pickup` |

Звуки по умолчанию пустые, чтобы игра не зависела от чужих id. Когда найдёшь звук в Toolbox: правый клик по нему → Copy Asset ID, вставь в Config в виде `"rbxassetid://123456789"`. Пустая строка `""` значит «звука нет».

Цвета города тоже там, таблица `Config.Colors`.

## Как добавить модели из Toolbox

Скрипт города использует только встроенные материалы и эффекты Roblox: `Neon`, `Concrete`, `Asphalt`, свет, частицы из текстур самого движка (`rbxasset://...`). Такие текстуры не пропадают, если каталог недоступен.

Свои модели подключаются так:

1. Нажми **Stop**, если игра запущена. Иначе модель исчезнет вместе с тестовой сессией.
2. **View → Toolbox**.
3. Найди модель (фонарь, машину, вывеску) и кликни по ней. Она появится в `Workspace`.
4. Двигай её инструментами Studio (Select / Move).
5. Сохрани место, Ctrl+S.
6. Снова Play. Скрипт удаляет только деталь с именем `Baseplate`, точки появления прямо в корне `Workspace` и старую папку `Map`. Твою модель он не трогает.

Удобно сложить свои декорации в папку `Workspace → Decor` (правый клик по Workspace → Insert Object → Folder, имя `Decor`). Так видно, что построил ты, а что скрипт.

Осторожнее с бесплатными моделями, внутри которых уже лежат скрипты. Чужой скрипт может быть вредоносным. Если модель нужна только как мебель, удали из неё чужие `Script`, прежде чем играть.

### Свой электрощиток

До Play создай `Part`, назови её ровно `ElectricBox`, поставь `Anchored` включённым и поставь на тротуар. При запуске `ChargeService` сам повесит подсказку, свет и искры. Имя должно совпасть буква в букву.

### Своя точка бандита

До Play создай `Part` с именем `EnemySpawn`. Включи `Anchored`, выключи `CanCollide`, поставь `Transparency` в 1 и подними деталь примерно на 4 студа над землёй. `EnemyService` найдёт её вместе с точками, которые строит карта.

## Если что-то сломалось

| Что видишь | Что проверить |
| --- | --- |
| В Output пусто, города нет | `GameServer` должен быть **Script**, не ModuleScript, и лежать в `ServerScriptService`. Галочка Disabled снята. |
| Красная строка `Infinite yield` на `Config` или другом имени | Нет объекта с таким именем, или он не в том родителе. Сверься с таблицей. |
| Красная строка про `require` | В ModuleScript стёрт `return` в конце, или вставлен не весь файл. |
| Полоска есть, город есть, выстрела нет | `WeaponClient` должен быть **LocalScript** в `StarterPlayerScripts`. В Output должна быть строка «Прицел готов». |
| Полоски нет | `ChargeHUD` — LocalScript в `StarterGui`. |
| Экран не темнеет на низком заряде | `ChargeEffects` — LocalScript в `StarterCharacterScripts`. |
| Упал сквозь карту в пустоту | В корне `Workspace` осталась лишняя `SpawnLocation` не от нашего скрипта. Удали её в режиме редактирования. Наш спавн создаётся на площади сам. |
| Куски города далеко пропадают | У `Workspace` в свойствах включён `StreamingEnabled`. Для этой карты выключи его: выдели Workspace, в Properties найди StreamingEnabled, сними галочку, сохрани. |
| Две пушки | Не создавай `Вольтган` руками. Его делает `WeaponService`. |
| Менял код во время Play, а после Stop всё пропало | Так и задумано. Правь скрипты, когда игра остановлена, и сохраняй место. С Rojo правь файлы на диске и оставляй `rojo serve` включённым. |

Ошибки в Output — твой главный инструмент. Читай первую красную строку: там имя скрипта и номер строки.

## Что делать дальше

Игра специально маленькая, чтобы её было не страшно менять.

- **Другой район.** Поменяй `Config.Map.Seed`. Из того же генератора получится другая раскладка домов. Следующий шаг — несколько сидов и смена карты, когда набрал, например, 10 убийств.
- **Сюжет.** Поставь на площадь NPC (можно скопировать сборку бандита и выключить у него атаку) с диалогом: «доживи 3 минуты», «заряди сердце до 100 и дойди до крыши», «принеси 3 батареи». Цель можно писать в тот же атрибут `StatusText`, его уже показывает интерфейс.
- **Режим «все отравлены».** Он почти готов: у каждого игрока своё сердце, щитки общие, огонь по своим включён. Добавь экран, когда в живых остался один, и поставь меньше щитков (убери лишние вызовы `addElectricBox` в `MapBuilder`). Можно сделать отдельное место или флаг `Config.Mode = "LastHeart"`.
- **Волны.** В `EnemyService` спавн уже завязан на точки `EnemySpawn`. Увеличивай их число каждые N секунд.
- **Боссы и уровни.** Отдельная точка спавна, больше `Health`, свой цвет визора.
- **Рекорд.** Сколько секунд прожил — сохрани через `DataStoreService`. Для этого игру нужно опубликовать, а в настройках места включить доступ к API. В тесте Play из Studio DataStore часто не работает, это нормально.
- **Анимации и звук сердца.** Сейчас руки и ноги бандита качаются кодом, без чужих анимаций. Свой звук сердцебиения кладётся в `Config.Sounds.Heartbeat`: клиент сам сделает его громче на низком заряде.
